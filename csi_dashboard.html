About this system

Every Wi-Fi receiver constantly measures Channel State Information (CSI) — how the radio signal was reshaped by everything it bounced off on the way from the router: walls, furniture, and people. That reshaping is normally thrown away once the data is decoded, but it's also a free, camera-free way to sense motion: a person walking through the room disturbs that pattern in a way an empty room doesn't.

This node is an ESP32-S3 that pings the router about 10 times a second to keep a steady stream of CSI readings, and a Random Forest model — trained on real labeled recordings of this room, empty vs. occupied — classifies short windows of that stream as EMPTY or MOVING. Every prediction is scored relative to a live calibration baseline (see the Calibration card below) rather than a fixed threshold, so the system adapts to this room's current conditions instead of memorizing one snapshot of it.

The Waterfall shows the raw signal itself — amplitude per subcarrier over time. The Motion energy chart shows the single derived number the model leans on most: how much that signal changes frame to frame. Empty rooms sit low and flat; movement spikes it.
